У [[Bash]] усі змінні немають типів, але інтерпретуються як рядкові або як числа у [[Арифметичні операції у bash|арифметичних операціях]] залежно від контексту.

> [!info] Загалом у bash розділяють два види змінних: [[Змінні оточення]] та змінні оболонки.

## Види змінних

- [[Масиви у Bash|масиви]]
- [[Змінні оточення]]
- локальні змінні (у функції або скрипті)
- константи (read-only, immutable)

## Оголошення змін

Присвоїти значення: 

```bash
path="/home/user"
```

Пуста зміна:

```bash
var=""
```

Константи:

```bash
readolny PI=3.14
declare -r MIN_SIZE=5
```

> [!warning] Присвоєння змінній значеня має бути без пробілів навколо `=`.

> [!tip] Щоб присвоїти змінні декілька значень, значеня повинні бути розділені `:`.
## Вивід зміни

```bash
echo $path
echo ${path}
echo "$path"
```

> [!warning] Важливо
> Завжди використовувати `"$var"` для уникнення інтерпретації [[Спеціальні символи у Bash|спеціальних символів]].

> [!note] `echo '$path'` — виведе [[літерал]], а не зміну.
