> ```bash
sudo ufw allow from <SERVER_IP> to any port <PORT>
> ```

```bash
sudo iptables -A INPUT -s <source_IP> -p tcp --dport <port_number> -j ACCEPT
```

> [!warning] Дозволяєте підключення лише необхідними IP-адресами

> [!tip] Для додаткової безпеки розгляньте можливість використання [[SSH tunnel|тунелювання SSH]]
