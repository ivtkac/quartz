- `#` — [[Коментарі у bash|коментар]]
- `;` — роздільник для команд (інколи повинен бути екранійованим)
- `;;`, `;;&` — термінатор у [[Розгалуження у bash|case option]]
- `.` — "dot" команда, те саме що [[source]]
- `./file` — "dot" як компонент файлу
- `""` — частковий рядок, інтерпретує вміст
- `''` — повний рядок, не інтерпретує вміст
- `,` — оператор кома для об'єднання декількох арифметичних операцій, але тільки останній вираз повертає значення
- `\` — [[Керувальні символи|Escape Sequences]]
- `/` — роздільник для [[Шлях до файлу]]
- \`\` — інтепретація виразу всередині як команди
- `:`  — [[null]]-команда
- `!` — інвертує [[exit status]]
- `*` — астерікс ([[wildcards у bash]]) для розширення файлів у [[globbing in bash]]
- `*` — [[Арифметичні операції у bash|арифметична операція]]
- `?` — test оператор або [[wildcards у bash|wildcard]]
- `$` — [[Змінні у bash]]
- `()` — групування команд
- [[Позиційні параметри у bash]]
- `{}` — блок коду
- `[]` — перевірити вираз (це [[bash builtins]])
- `[[]]` — перевірити вираз (це [[keyword|ключове слово]])
- [[Перенаправлення потоків]]
- [[Конвеєр (pipes)]]
