Пряме виконання:

```bash
sh scriptname
# або
bash scriptname
```

> [!warning] Цей спосіб вимикає [[стандартні потоки|stdin]] для [[Скрипти|cкрипту]].

Або зробити скрипт виконаним ([[chmod]]):

```bash
chmod 555 scriptname
```

```bash
# Всім користувачам: читання + виконання
chmod +rx scriptname

# Тільки власнику файлу: читання + виконання  
chmod u+rx scriptname
```

Після чого можна запустити:

```bash
./scriptname
```
