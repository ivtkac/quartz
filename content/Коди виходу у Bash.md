| Код     | Опис                                       | Приклад                   | Коментарі                                                           |
| ------- | ------------------------------------------ | ------------------------- | ------------------------------------------------------------------- |
| `1`     | усі звичайні помилки                       | `let "var1=1/0"`          | Помилка типу "не можна ділити на нуль" та інші неприпустимі помилки |
| `2`     | Неправильне використання [[bash builtins]] | `empty_function() {}`     | Відсутність ключового слова або помилка доступу                     |
| `126`   | Викликану команду, не можна виконати       | `/dev/null`               | Помилка доступу або команда не є для виконання                      |
| `127`   | [[Command not found]]                      | `illegal_command`         | Такої команди не існує або її немає у `$PATH`                       |
| `128`   | Неправильний аргумент для команди `exit`   | `exit 3.1459`             | `exit` приймає тільки значення від 0-255                            |
| `128+n` | Помилка [[сигнали процесів\|сигналу]] "n"  | `kill -9 $PPID of script` | `$?` поверне 137 (128+9)                                            |
| `130`   | Скрипт завершено через `CTRL+C`            | `CTRL-C`                  | `Ctrl-C` має код сигналу $2$ (130=128+2)                            |
| `255`   | Код завершення вийшов за межі              | `exit -1`                 | `exit` приймає тільки значення від $0-255$                          |
