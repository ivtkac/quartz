> [!tldr]
> **Apache (httpd)** — це вільне відкрите програмне забезпечення, яке обслуговує веб-сторінки для браузерів.
>

> Простими словами виконує роботу [[Веб-сервер|вебсервера]].

## Можливості Apache

> [!example] Можливості Apache
> - Працювати з статичним контентом (html, css, js)
> - Обробляти динамічний контент (PHP, Python, CGI)
> - Розміщувати декілька веб-сайтів ([віртуальні хости](https://httpd.apache.org/docs/2.4/vhosts/examples.html))
> - Захистит сторінки (SSL/HTTPS)
> - Контролювати доступ ([[Як встановити пароль для аутентифікації у Apache?|паролі]], обмеження IP-адрес)
