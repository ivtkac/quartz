> [!tldr]
> **Командою**, може бути одне з :
> 
> - виконуваний файл
> - команда, вбудована у саму оболонку
> - функція оболонки
> - псевдонім ([[alias]])

**Команда** може виконуватись самостійно або вживатися з аргументами, які модифікують роботу команди (квадратні дужки означають, що аргумент не обов'язковий).

```
команда [-ключ] [--довгий-ключ] файл
command [-key] [--long-key] file
```

> [!example] Типи команд
> - [[alias]] — псевдонім, скорочення для команди
> - keyword — зарезервоване слово (символ, оператор: `for`, `while`)
> - [[Функції у bash|function]] — підпрограма, іменований блок коду
> - [[bash builtins|builtin]] — команда, вбудована в облонку
> - [[файл]] — зовнішній, виконуваний файл (на диску)
