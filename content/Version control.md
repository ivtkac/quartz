> [!tldr]
> **Version control** is a system that records changes over time and allow you reverted to some state later.

> [!example] **Usage**
> - Revert selected files back to a previous state
> - Revert the entire project to a previous state
> - Compare changes over time
> - See who last modified something
> - See who introduced an issue and when

## Types

- **Local**: a simple database with changes to files under revision control
- **Centralized**: a single server with version files, and clients that check out files from a server
- **Distributed**: mirror repository, including its full history (like full backup of all the data)
