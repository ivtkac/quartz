| **Команда**         | **Опис**              |
| ------------------- | --------------------- |
| `SHOW DATABASES`    | Список усіх баз даних |
| `USE database_name` | Вибір активної БД     |
| `CREATE DATABASE`   | Створення БД          |
| `DROP DATABASE`     | Видалення БД          |
