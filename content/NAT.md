> [!tldr]
> **NAT** — це механізм, який дозволяє кільком пристроям у [[локальна мережа|приватній мережі]] використовувати одну або декілька публічних [[IP]]-адрес для доступу до [[Інтернет|інтернету]].

## Види NAT

- [[Статичний NAT|SNAT]]
- [[Динамічний NAT|DNAT]]
- [[PAT]]

## NAT термінологія

- **внутрішня локальна адреса**: приватна IP у локальній мережі призначена хосту
- **внутрішня глобальна адреса**: публічна IP призначена до роутера з NAT
- **зовнішня глобальна адреса**: публічна IP адреса призначена хосту за межами локальної
- **зовнішня локальна адреса**: приватна IP призначена хосту за межами локальної мережі
