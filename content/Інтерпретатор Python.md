[[Інтерпретатор]] [[Python]] можна використовувати у двох режимах: **інтерактивному** та [[скрипти|скриптовому]].

У інтерактивному режимі Python реагує на кожен [[Оператор]] під час введення тексту.
У сценарійному режимі ми надаємо Python файл, у якому він інтерпретує усі оператори.

> [!example] Активувати інтерактивний режим
> ```bash
> python
> ```
