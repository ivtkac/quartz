> [!info]  `set` — [[bash builtins|вбудована команда]] [[Bash]] для керування параметрами [[оболонка|оболонки]] та [[позиційні параметри у bash|позиційними параметрами]].

> [!note] Щоб увімкнути параметр достатньо написати опцію через `set -option-name` або `set -option-abbrev`.

> [!note] Щоб вимкнути параметр достатньо написати опцію через "+": `set +option-abbrev`.


> [!example] Опції
> - `-e` (errexit) — завершити скрипт при помилці
> - `-u` (nounset) — помилка при використанні неініціалізованої змінни
> -  `-x` (xtrace) — те саме, що і `-v` (але більш розширений вивід DEBUG mode)
> - `-o pipefail` (pipe failure) — Змушує [[Конвеєр (pipes)]] повернути помилку, якщо остання команда повернула ненульове значення

## Додатково

| Команда              | Опис                               |
| -------------------- | ---------------------------------- |
| `set var1 var2 var3` | `var1=$1, var2=$2, var3=$3`        |
| `set --`             | Очистити усі позиційні параметри   |
| `set -- "@" extra`   | Додати `extra` до кінця параметрів |
