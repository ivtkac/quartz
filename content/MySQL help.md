[[MySQL]] має вбудовану систему довідки, доступну через команди:

- `\h` - загальна довідка
- `HELP 'search_string'` - пошук по темах
- `HELP 'data types'` - довідка по типах даних
- `HELP 'create table'` - довідка по створенню таблиць
