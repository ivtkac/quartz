- **assigned** using `let` keyword
- **print** to standard output by `print!()` or `println!()`
- **scope** of variable defined by the **block of code** in which it is declared
- **function** is a named block of code that is **reusable**
- **shadowing** allows a variable to be **re-declared** in the **same scope** with **same name**
