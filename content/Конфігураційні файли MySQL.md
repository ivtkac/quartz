- [[Основні налаштування MySQL|/etc/my.cnf]] — Файл для усіх серверів
- `~/.my.cnf` — Користувацькі налаштування
- `/var/lib/mysql/(mysqld-)auto.conf` — Унікальний ідентифікатор сервера (автогенерується)
- `/var/log/mysql` — Логи
