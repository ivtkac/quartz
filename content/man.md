> [!info] Переглянути довідку про команду або утиліту.

```bash
man program
```

- `man cat` — отрмимати ґід по `cat`
- `man -k` — вивести список усіх команд, що містять "ключове слово" у описі
- `man -f` — отримати короткий опис про команду

> [!example] Розділи 
> - $1$ — команди користувача
> - $2$ — інтерфейси для системних викликів ядра
> - $3$ — інтерфейси для бібліотеки C
> - $4$ — спеціальні файли, такі як вузли пристроїв та диски
> - $5$ — формати файлів
> - $6$ — ігри та розваги, такі як заставки
> - $7$ — різне
> - $8$ — команди системного адміністрування
