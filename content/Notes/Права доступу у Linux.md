| Тип права       | Опис      | Числове представлення |
| --------------- | --------- | --------------------- |
| **r (read)**    | читання   | 4                     |
| **w (write)**   | запис     | 2                     |
| **x (execute)** | виконання | 1                     |

> [!note] Якщо права у числовому представлення **непарне число**, то користувач завжди матиме доступ до виконання.

## Права доступу для каталогів

| **Права** | **Що можна зробит з файлом?** | **Що можна зробити з каталогом?**  |
| --------- | ----------------------------- | ---------------------------------- |
| `r`       | прочитати вміст               | переглянути список файлів ([[ls]]) |
| `w`       | змінити вміст                 | створити видалити/файли            |
| `x`       | виконати                      | перейти в каталог ([[cd]])         |

## Спеціальні права

| **Назва**           | **Опис**                            | **Команда**                     |
| ------------------- | ----------------------------------- | ------------------------------- |
| SUID (set user ID)  | Виконувати від імені власника файлу | `chmod u+s` або `chmod 4755`    |
| SGID (set group ID) | Виконувати від імені групи файлу    | `chmod g+s` або `chmod 2755`    |
| Sticky bit          | Тільки власник може видаляти файл   | `chmod +t dir` або `chmod 1755` |
